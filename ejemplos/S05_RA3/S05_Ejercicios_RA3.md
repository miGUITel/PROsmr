# S05 · Dos ejercicios opcionales de RA3

Copia el ejemplo correspondiente fuera del repositorio. Cada propuesta ocupa unos 5–10 minutos y no necesita Internet.

## 1. Aviso de batería

Adapta `S05_Seleccion.java` para mostrar `Conectar cargador` cuando la batería sea menor que 20, y `Bateria suficiente` en los demás casos.

Prueba los valores 19, 20 y 21. Anota qué mensaje esperas en cada caso y explica por qué has elegido `<` o `<=`. Como ampliación, añade un mensaje para valores fuera del intervalo de 0 a 100.

## 2. Etiquetas del aula

Adapta el primer `for` de `S05_Bucles.java` para mostrar las etiquetas `PC-1`, `PC-2`, `PC-3` y `PC-4`.

Haz que el límite dependa de una variable `cantidad` y prueba 0, 1 y 4. Comprueba que aparecen exactamente tantas líneas como equipos. Como ampliación, muestra también cuántos equipos se han etiquetado.
