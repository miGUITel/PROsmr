# S06 · Dos ejercicios opcionales de RA4

Propuestas de 5–10 minutos. Trabaja en una copia personal y sin Internet.

## 1. Precio en la consola

Parte de `S06_Consola.java`. Solicita el nombre de un periférico y muestra ese nombre junto a un precio fijo de `12.345` euros con dos decimales. No hace falta pedir el precio por teclado.

Identifica qué instrucción lee, cuál muestra y cuál aplica el formato. Explica si el formato cambia el valor almacenado en la variable.

## 2. Lectura de un inventario

Utiliza una carpeta de prueba personal para ejecutar `S06_Ficheros.java`. Localiza `datos-pro/inventario.csv`, identifica la cabecera y las dos filas de equipos.

Con un editor de texto, añade una fila con un identificador nuevo, el nombre de un equipo y su RAM. Guarda el archivo y ejecuta de nuevo el programa. Comprueba que recupera la fila añadida y que el ejemplo no reemplaza el contenido existente.

Si no se ejecuta código en ese momento, escribe en papel la fila que añadirías y señala qué llamada Java permitiría leerla.
