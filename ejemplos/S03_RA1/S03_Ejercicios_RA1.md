# S03 · Dos ejercicios opcionales de RA1

Copia el ejemplo a tu carpeta personal antes de modificarlo. Cada propuesta está pensada para unos 5–10 minutos y se puede realizar sin Internet.

## 1. Ficha de un router

Parte de `S03_FichaEquipo.java`. Sustituye los datos del equipo por el modelo de un router, su número de puertos, su precio, si tiene wifi y una letra que identifique la zona. Elige un tipo para cada dato y añade una constante con el nombre del aula.

Muestra todos los datos con etiquetas. Cambia el número de puertos y vuelve a ejecutar. Explica qué variable has cambiado y por qué su tipo resulta adecuado.

## 2. Cables para el aula

Un cable cuesta 3.50 euros. Declara una variable con la cantidad de cables y otra con el precio unitario. Calcula y muestra el coste de 4 cables. Después cambia únicamente la cantidad a 7.

Comprueba el cálculo a mano antes de ejecutar. Como pequeño reto adicional, parte del texto `"4"` y conviértelo a entero para obtener la cantidad. No necesitas leer desde teclado.
