# Actividad 1: mi primer cambio en Java

Tiempo recomendado: **30 minutos**.

Archivo de partida: `S01_HolaSMR.java`.

## Preparación

1. Actualiza el repositorio de materiales mediante `git pull --ff-only`.
2. Copia `S01_HolaSMR.java` a tu carpeta personal de prácticas.
3. Trabaja siempre sobre la copia personal. No modifiques el archivo del repositorio.

## Mínimo

1. Abre el archivo en VSCode.
2. Ejecuta el programa sin cambiar nada.
3. Cambia el valor de `nombreAlumno` por tu nombre.
4. Cambia `numeroSesion` a `1`.
5. Sustituye el mensaje final por una frase que explique algo que quieras aprender.
6. Ejecuta otra vez.
7. Comprueba que la consola muestra tus datos.

## Prueba esperada

La salida debe tener cuatro líneas y contener:

- Tu nombre.
- El nombre del módulo.
- El número 1.
- Tu objetivo personal.

## Pequeño experimento con errores

1. Quita el punto y coma de una instrucción.
2. Ejecuta.
3. Lee el primer mensaje de error.
4. Restaura el punto y coma y vuelve a ejecutar.

Anota: ¿qué línea indicaba el error y qué símbolo faltaba?

## Mejora opcional

Añade una quinta línea que muestre el ciclo y el curso.

## Entrega

- Archivo Java que funciona.
- `README.md` con estas tres frases completadas:

```text
He cambiado...
He comprobado que funciona mediante...
El error que he provocado se resolvía...
```

- Entrega los dos archivos mediante el Aula Virtual cuando lo indique el profesor.
