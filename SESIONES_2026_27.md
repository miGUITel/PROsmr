# Fundamentos de la programación: materiales del curso

Este repositorio distribuye los recursos del módulo. El profesor publica los cambios y el alumnado los descarga con acceso de lectura.

## Flujo de trabajo

1. Abre la carpeta del repositorio.
2. Actualízala mediante:

```bash
git pull --ff-only
```

3. Consulta los apuntes, ejemplos y tareas de la sesión correspondiente.
4. Copia la plantilla de la tarea a una carpeta personal situada fuera del repositorio.
5. Trabaja sobre la copia personal.
6. Entrega el resultado mediante el Aula Virtual.

El alumnado no necesita realizar `commit` ni `push` en este módulo. Los commits publicados por el profesor permiten observar cómo evoluciona el material.
